MeteoAPI
Meteo API

url parameters

  • model - name of one of available models
  • grid - name of one of available grids
  • coordinates - point from grid in format [row,col]. Row and col are ints and have to be allowed grid point. If you want to find closest points on grid you can use nearbyPoints api endpoint.
  • field - field name
  • level - level name
  • date - date format in iso 8601 like format(yyyy-mm-ddTHH). Available HH values are 00, 06, 12, 18, 24. Note that forecast won't be instantly available on our service.
  • point - Latitude and longitude in format [lat,lon]. Lat and lon are floats(eg. "52.2333,21.0167")


All api requests requires Authorization header with value Token {your api token}.

There is limited support for xml(only for forecast endpoint so far). Please use json format as your first choice.
To use xml header "Accept: application/xml" must be added.

Time format in service is iso 8601 standard.

Request fetched from the database are cached.
For this reason making same request more often than in 1 minute doesn't make any sense.

        • Dates for which there is field in db

        Implementation Notes

        Dates for which there is field in db. Result is given with run-length encoding compression. For instance if starting date is 2017-11-11T00, count is 3 and interval is 6 there are following forecast dates: 2017-11-11T00, 2017-11-11T06, 2017-11-11T12.

        Response data:

    "dates": [

            'starting-date': DATE,
